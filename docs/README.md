## ۱) پروژه در یک پاراگراف

FlowStudio ارکستراتورِ تولیدِ محتوایِ بصری با هوشِ مصنوعی است: از یک ایده،
با هر طولی (چند ثانیه تا فیلمِ کامل)، خروجیِ آمادهٔ انتشار. پروژهٔ **مستقل**
است — مخزن، دیتابیس و کانتینرِ خودش را دارد؛ فقط **کد** از ماژول‌های
وبکستینگ کپی می‌شود، نه سرویس. شعار: **از ایده تا دیده**.

- مخزن: `github.com/wbcastingdm/flowstudio` (لوکال: `~/Projects/flowstudio`)
- زنده: `https://flowstudio.webcasting.ir`
- سرور: `62.220.123.55` · مسیر: `/opt/flowstudio`

## ۳) 🔴 دو کاری که فقط از دستِ مالک برمی‌آید

### الف) کلیدِ واقعیِ تجمیع‌کننده
بدونِ آن `/studio` خطای صادقانهٔ ۵۰۳ می‌دهد («هیچ مدلِ TEXTی ثبت نشده»).
از `/admin/models` فرمِ «درگاهِ جدید»: نام دلخواه · `baseUrl` سازگار با
OpenAI (معمولاً `/v1`) · کلیدِ واقعی. بعد در فرمِ کناری مدل را با نوعِ
`TEXT` و تیکِ «مصرفِ تجاری مجاز» اضافه کن.
**بلافاصله بعد از این `/studio` کار می‌کند — هیچ کدِ دیگری لازم نیست.**

> کلید رمزنگاری‌شده (AES-256-GCM) در دیتابیسِ خودِ سرور می‌نشیند.
> عمداً هیچ کلیدی از وبکستینگ یا `~/.9router` برداشته نشد.

### ب) نیم‌سرورِ `flowstudio.ir`
دامنه ثبت شده ولی **NS ندارد** (`dig +short flowstudio.ir NS` خالی است).
باید در پنلِ ثبت‌کننده نیم‌سرورها به Cloudflare داده شود، بعد رکوردِ `A`
به `62.220.123.55`. کانفیگِ nginx و دستورِ گواهی از قبل آماده است:
`deploy/nginx/flowstudio.ir.conf`.

## ۴) فازها — کجا بودیم، کجا می‌رویم

### ✅ فازِ صفر — راه‌اندازیِ پایه · تمام
مونوریپو با npm workspaces · NestJS + Prisma + PostgreSQL 16 + Redis 7 ·
شِمای ۱۱ مدلی · `GET /health` که واقعاً `SELECT 1` می‌زند.
**شواهد:** `evidence/sprint-0.txt` (هر شش فرمانِ معیارِ تمام‌شدن اجرا شد)

### ✅ فازِ یک — لایهٔ درگاهِ AI · تمام
`AiProvider`/`AiModel` با قراردادِ قابلیتِ پنج‌فیلدی · روترِ کاندیدا با
failover (الگو از `ai-provider.service.ts` وبکستینگ) · رمزنگاریِ کلید ·
صفحهٔ ادمین · `POST /api/chat`.
**گاردریل:** مدلِ `commercialUse=false` هرگز انتخاب نمی‌شود، حتی ارزان‌ترین.

### 🔶 فازِ دو — ایده تا بریف · لوله‌کشی تمام، تولیدِ واقعی تأییدنشده
ایده → پرامپت (با شش قاعدهٔ ABCDِ گوگل از `knowledge/rules/E-class-v1.md`)
→ پارسِ سخت‌گیرانهٔ JSON → ذخیره به شکلِ `Project → Sequence → Shot`.
همیشه رایگان (`costActual = 0`).
**چرا «تمام» نیست:** با سرورِ ماکِ محلی تست شد؛ با مدلِ واقعی هنوز نه.
منتظرِ بندِ ۳-الف. **شواهد:** `evidence/sprint-2.txt`

### ⬜ فازِ سه — تولیدِ تصویر + کیفِ پول (اولین مرحلهٔ پرداختی)
چرخهٔ `hold → settle/release`. **بلوکر:** `D-006` — عددِ بودجهٔ ۹۰ روز.

### ⬜ فازِ چهار — پروفایل و کتابخانهٔ کاربر
تاریخچهٔ پروژه‌ها. اینجا جای‌گیرِ موقتِ کاربر هم برداشته می‌شود (بندِ ۶).

### 🔴 فازِ پنج — پروبِ تجمیع‌کنندهٔ ویدیو · گیتِ کلِ کارِ ویدیو
یک `curl` واقعی تا معلوم شود کدام تجمیع‌کننده مدلِ ویدیو دارد و شکلِ

پربازده‌ترین نیم‌ساعتِ کلِ پروژه — چهار فازِ بعدی را از حالتِ «طراحی» بیرون می‌آورد.

## ۶) تله‌ها و بدهی‌های ثبت‌شده — قبل از دست‌زدن بخوان

1. 🔴 **Prisma روی alpine** بدونِ `binaryTargets = ["native",
   "linux-musl-openssl-3.0.x"]` کرش‌لوپ می‌زند: `libssl.so.1.1: No such file`.
   **فقط داخلِ داکر دیده می‌شود، روی مک هرگز.**
2. 🔴 **`WORKDIR /app` + روتِ `app/app/`** ⇒ Next بی‌صدا `/` را با محتوای
   `/app` می‌سازد. برایِ همین `WORKDIR` در هر دو Dockerfile `/srv/*` است.
3. 🔴 **nginxِ سرور کانتینر است** (`wbc_nginx`) با یک فایلِ کانفیگِ واحد.
   فایلِ جدا در `conf.d` **بی‌اثر** است؛ باید به انتهای
   `/opt/webcasting-platform/deploy/turkey/nginx.conf` اضافه شود، بعد
   `nginx -t` و `nginx -s reload`. بدونِ reload هیچ اثری ندارد.
4. 🔴 **`127.0.0.1` از داخلِ کانتینرِ nginx خودِ nginx است** — کانتینرهای ما
   روی `172.18.0.1` بایند می‌شوند.
5. ⚠️ **حالتِ watch (`nest start --watch`) قفل می‌کند** و نسخهٔ قدیمی جواب
   می‌دهد. برایِ تستِ لوکال `npm run build` بعد `node dist/src/main.js`.
6. ⚠️ **جای‌گیرِ موقت:** تا آمدنِ OTP، پروژه‌ها به کاربرِ `+000000000000`
   نسبت داده می‌شوند. تصمیمِ محصولی نیست — در فازِ ۴ برداشته می‌شود.

## ۷) قاعده‌های حاکم — غیرقابلِ مذاکره

1. **تصمیم قبل از کد.** اگر دروازهٔ تصمیمِ یک فاز باز است، فاز شروع نمی‌شود.
   مقدارِ پیش‌فرضِ سکوت‌آمیز = تصمیمِ دزدیده‌شده.
2. **مجری حقِ تأییدِ خودش را ندارد.** هر ادعا با شواهدِ ترمینال در
   `evidence/sprint-N.txt`. کدِ ۲۰۰ اثباتِ تولید نیست.
3. **هرگز به کانتینر، شبکه یا دیتابیسِ وبکستینگ دست نزن.** فقط هم‌خانه‌ایم.
4. **جهتِ اتصال:** وبکستینگ → FlowStudio. هرگز برعکس.
5. **نامِ هیچ مدلی در کد hard-code نشود** — مدل ردیفِ داده است.
6. **`hold` قبل از خرج، `release` در `catch`.**
7. **گیتِ انسانی پیش از خرجِ پول، نه بعد از آن.**

## ۸) دستورهای عملیاتی

```bash
# اجرا لوکال
cd ~/Projects/flowstudio
docker compose up -d                      # postgres + redis
npm install
npm run build --workspace=@flowstudio/api
cd apps/api && node dist/src/main.js &    # API روی :3200
cd apps/web && npm run dev &              # وب روی :3100

# دیپلوی
rsync -az --delete --exclude node_modules --exclude .next --exclude .git \
  --exclude dist --exclude '.env' --exclude 'docs/*.pdf' --exclude 'docs/*.patch' \
  ./ root@62.220.123.55:/opt/flowstudio/
ssh root@62.220.123.55 'cd /opt/flowstudio && docker compose -p flowstudio \
  --env-file .env -f deploy/docker-compose.prod.yml up -d --build'

# مهاجرتِ دیتابیس روی سرور
ssh root@62.220.123.55 'docker exec flowstudio_api npx prisma db push \
  --schema=prisma/schema.prisma --skip-generate'

# بررسیِ سلامت
curl -s https://flowstudio.webcasting.ir/health
ssh root@62.220.123.55 'docker ps | grep flowstudio'
```
