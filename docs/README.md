## ۳) وضعیت در یک نگاه

**آنچه زنده است و کار می‌کند**

| مسیر | چیست |
|---|---|
| `/studio` | ایده تا شات‌لیست، با کارگردانی هر نما |
| `/login` | ورود با موبایل و کد · 🟡 سندباکس: کد ثابت `123456` |
| `/library` | آرشیو کاربر، فقط آثار خودش |
| `/w/[id]` · `/u/[id]` · `/discover` | صفحه عمومی اثر، پروفایل سازنده، کشف |
| `/admin` · `/admin/models` | پنل راهبر و رجیستری درگاه‌ها · 🔒 قفل با راز |
| `/health` | سلامت API و پایگاه داده |

موتور: رجیستری درگاه با افتادن به بعدی، کیف پول با رزرو و تسویه و آزادسازی،
صف با قفل دیتابیسی، رجیستری محصول، دارایی با کلید هش محتوا، و انتشار با دو
دروازه. سی موجودیت در شما.

**آنچه وجود ندارد — صریح**

- 🔴 **هیچ کارگری صف را مصرف نمی‌کند** ⇒ هیچ گامی هرگز اجرا نمی‌شود
- 🔴 **هیچ ردیف تولیدی نوشته نمی‌شود** ⇒ معیار انتخاب مدل محاسبه‌ناپذیر است
- هیچ آداپتر تصویر و ویدیو و گفتار — تنها مسیر بیرونی، فراخوان متنی است
- هیچ مونتاژی، هیچ متن روی تصویر، هیچ زیرنویسی
- انطباق فقط جدول است، بدون منطق و بدون صفحه بازبینی
- موسیقی، پرداخت، پیامک، فاکتور، رابط فلک، و پشتیبان‌گیری پایگاه داده

جزئیات کامل با شواهد: سند `104` بخش ۲.

## ۵) تله‌ها — پیش از دست زدن بخوان

1. 🔴 **پریزما روی ایمیج سبک** بدون هدف باینری صریح کرش‌لوپ می‌زند. فقط داخل
   داکر دیده می‌شود، روی مک هرگز.
2. 🔴 **`WORKDIR /app` با روت `app/app/`** ⇒ Next بی‌صدا صفحه `/` را با محتوای
   `/app` می‌سازد و همه نشانه‌ها سبز می‌مانند. برای همین `WORKDIR` هر دو ایمیج
   `/srv/*` است.
3. 🔴 **nginx سرور کانتینر است** با یک فایل کانفیگ واحد و مشترک بین همه
   سایت‌ها. فایل جدا در `conf.d` بی‌اثر است. بلوک مسیر رابط برنامه‌نویسی در آن
   ده‌ها بار تکرار شده — هر درج الگویی بی‌سروصدا به همه سایت‌ها می‌رود. ویرایش
   با شمردن آکولاد، بعد آزمایش، بعد بارگذاری دوباره.
4. 🔴 **`127.0.0.1` از داخل کانتینر nginx خود nginx است** — کانتینرهای ما روی
   `172.18.0.1` بایند می‌شوند.
5. 🔴 **امکان درج متن ابزار ویدیو فارسی را خراب می‌کند** و هیچ خطایی نمی‌دهد.
   هر متن فارسی از موتور اچ‌تی‌ام‌ال رد می‌شود. سند `105` بند ۱.
6. ⚠️ **حالت پایش خودکار سرور توسعه قفل می‌کند** و نسخه قدیمی جواب می‌دهد.
   برای آزمون لوکال: ساخت، بعد اجرای مستقیم.
7. ⚠️ **آزمون‌ها باید داخل پوشه خود سرویس کامپایل شوند**، وگرنه وابستگی‌ها پیدا
   نمی‌شوند و ممکن است نسخه کهنه اجرا شود.
8. ⚠️ **درخت کاری میان چند لاین مشترک است.** فقط تکه کار خودت را مرحله‌بندی کن.
9. ⚠️ **حالت سندباکس ورود روشن است** — هر شماره با کد ثابت وارد می‌شود. پیش از
   اولین ریال واقعی باید بسته شود.

1. **تصمیم پیش از کد.** دروازه باز یعنی اسپرینت شروع نمی‌شود. پیش‌فرض
   خاموش یعنی تصمیم دزدیده‌شده.
2. **مجری حق تایید خودش را ندارد.** هر ادعا با شواهد ترمینال در
   `evidence/sprint-N.txt`. کد ۲۰۰ اثبات تولید نیست.
3. **هرگز به کانتینر، شبکه یا پایگاه داده وبکستینگ دست نزن.** فقط هم‌خانه‌ایم؛
   هر نیاز فرامرزی از راه شبکه رد می‌شود، نه از راه پایگاه داده.
4. **جهت اتصال:** وبکستینگ به فلواستودیو. هرگز برعکس.
5. **نام هیچ مدلی در کد ثابت نوشته نمی‌شود** — مدل یک ردیف داده است.
6. **رزرو پیش از خرج، آزادسازی در شکست.**
7. **گیت انسانی پیش از خرج پول، نه بعد از آن.**
8. **خروجی در سطح نما ذخیره می‌شود**، نه فقط فایل نهایی.
9. **متن هرگز داخل پیکسل مدل نمی‌رود** — همیشه لایه شفاف مستقل.

## ۷) دستورهای عملیاتی

```bash
# اجرا لوکال — وب روی 3100، API روی 3250
cd ~/Projects/flowstudio
docker compose up -d                      # postgres + redis
npm install
npm run build --workspace=@flowstudio/api
cd apps/api && node dist/src/main.js &
cd apps/web && npm run dev &

# دیپلوی
rsync -az --delete --exclude node_modules --exclude .next --exclude .git \
  --exclude dist --exclude '.env' --exclude 'docs/*.pdf' --exclude 'docs/*.patch' \
  ./ root@62.220.123.55:/opt/flowstudio/
ssh root@62.220.123.55 'cd /opt/flowstudio && docker compose -p flowstudio \
  --env-file .env -f deploy/docker-compose.prod.yml up -d --build'

# مهاجرت پایگاه داده روی سرور
ssh root@62.220.123.55 'docker exec flowstudio_api npx prisma db push \
  --schema=prisma/schema.prisma --skip-generate'

# بررسی سلامت
curl -s https://flowstudio.ir/health
ssh root@62.220.123.55 'docker ps | grep flowstudio'

# گرپ‌های قرارداد جدایش — هر چهار باید خالی برگردند
grep -rniE "gpt-|claude-|gemini|veo|runway|kling" apps/api/src --include='*.ts'
grep -rnE "^\s*@Cron\(" apps/api/src packages --include='*.ts'
grep -rni "webcasting" apps/api/src --include='*.ts'
grep -rniE "queryRaw" apps/api/src --include='*.ts'
```
