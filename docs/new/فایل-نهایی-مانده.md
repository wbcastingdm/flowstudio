## 🔴 پیش از هر کار — هفت قاعده و پنج دام

**قاعده‌های دائمی:**
۱. **هرگز به کانتینر، شبکه یا دیتابیسِ وبکستینگ دست نزن.** فقط هم‌خانه‌ایم. هر نیازِ
   فرامرزی از راهِ شبکه رد می‌شود، نه از راهِ دیتابیس. جهتِ اتصال همیشه
   **وبکستینگ ← فلواستودیو** است، هرگز برعکس.
۲. **تصمیم پیش از کد.** دروازهٔ باز = اسپرینت شروع نمی‌شود. «پیش‌فرضِ خاموش» یعنی
   تصمیمِ دزدیده‌شده.
۳. **نامِ هیچ مدلی در کد ثابت نوشته نمی‌شود.** مدل یک ردیفِ داده است و روتر روی
   قابلیت تصمیم می‌گیرد. چهار گرپِ قراردادِ جدایش باید همیشه خالی برگردند:
   ```bash
   grep -rniE "gpt-|claude-|gemini|veo|runway|kling" apps/api/src --include='*.ts'
   ```
۴. **رزرو پیش از خرج، آزادسازی در شکست.** هیچ سکه‌ای به‌خاطرِ خطا بلعیده نمی‌شود.
۵. **گیتِ انسانی پیش از خرجِ پول، نه بعد از آن.**
۶. **خروجی در سطحِ نما ذخیره می‌شود، نه فقط فایلِ نهایی** — وگرنه اولین ابزارِ ویرایش
   یعنی بازسازیِ کلِ خطِ تولید.
۷. **مجری حقِ تأییدِ خودش را ندارد.** هر ادعا فایلِ شواهد در `evidence/` دارد.
   **کدِ ۲۰۰ اثباتِ تولید نیست.**

**دام‌هایی که وقت گرفته‌اند:**
- 🔴 `WORKDIR /app` + روتِ `app/app/` ⇒ Next **بی‌صدا** صفحهٔ `/` را با محتوای `/app`
  می‌سازد. بیلد سبز، Route سبز، healthcheck سبز. روی مک درست است و **فقط داخلِ داکر
  خراب**. رفع: `WORKDIR /srv/web`.
- 🔴 `nginx` روی سرور **کانتینر** است (`wbc_nginx`) و کلِ کانفیگ یک فایلِ ۳۲ کیلوبایتیِ
  مشترکِ همهٔ سایت‌هاست. **گذاشتنِ فایلِ جدا در `conf.d` هیچ اثری ندارد.** هر درجِ
  الگویی بی‌سروصدا به همهٔ سایت‌ها می‌رود — ویرایش باید با شمردنِ آکولاد به بلاکِ
  خودمان محدود شود.
- 🔴 `127.0.0.1` از داخلِ کانتینرِ nginx **خودِ nginx است**. بایند روی `172.18.0.1`.
- کتابخانهٔ پریزما روی ایمیجِ آلپاین هدفِ باینریِ صریح می‌خواهد، وگرنه کانتینر در
  حلقهٔ کرش می‌افتد — این خطا فقط داخلِ داکر دیده می‌شود.
- بدونِ `nginx -s reload` هیچ تغییری اثر ندارد.

۱. **کانتینرِ کارگرِ جدا با حلقهٔ برداشتنِ کار، بیرون از پروسهٔ API** (بدهی ب-۱۰) —
   قاعدهٔ «هیچ کرونی داخلِ API» نمی‌شکند و چند رپلیکا شدنِ API خطری ندارد
۲. ساختِ گرافِ گام‌ها از شات‌لیست: تصویرِ کلیدی، حرکت، ارتقا
۳. تقسیمِ پاکتِ بودجه بین نماها بر پایهٔ وزن — نمای قهرمان و نمای پرکننده سهمِ برابر
   نمی‌گیرند
۴. **پیش‌بررسیِ جا شدنِ پلان در پاکت و اعلام پیش از اولین خرج** — نه تنزلِ بی‌صدا وسطِ کار
۵. ثبتِ ردیفِ تولید با شمارهٔ تلاش برای هر تلاش، موفق یا شکست‌خورده (بدهی ب-۲)
۶. صفحهٔ صفِ کار در پنلِ راهبر با امکانِ بازگرداندنِ کارِ گیرکرده

**معیارِ تمام‌شدن:** پلانی با ده گام روی صف اجرا شود و وضعیتِ هر گام از پنل دیده شود؛
**با کشتنِ کارگر وسطِ کار، کارِ یخ‌زده به صف برگردد و موجودیِ کاربر دقیقاً برابرِ پیش از
شروع بماند**؛ و برای هر تلاش یک ردیفِ تولید ثبت شده باشد.

### S4 — اولین فایلِ قابلِ تماشا (۴۸ ساعت)
**اولین باری که محصول کارِ خودش را انجام می‌دهد** — بدونِ هیچ مدلِ ویدیویی و بدونِ
هیچ خریدِ خارجی.

نکاتِ حیاتی: ایمیجِ کارگر با ابزارِ ویدیو و موتورِ رندر (ایمیجِ API سبک بماند، بدهی ب-۹) ·
ذخیرهٔ خروجی **در سطحِ نما** به‌عنوانِ داراییِ مستقل · مونتاژ با نسبتِ درست (بستنِ ب-۳) ·
**موتورِ لایهٔ شفاف با خروجیِ آلفادار** — هر متنی که روی تصویر می‌نشیند لایهٔ مستقل است،
نه بخشی از پیکسلی که مدل ساخته.

🔴 **چرا لایهٔ متن جداست — یک تصمیم که سه چیز را حل می‌کند:** کیفیتِ متنِ فارسی رایگان
به دست می‌آید؛ نسخهٔ زبانِ دوم تقریباً رایگان می‌شود چون فقط لایه دوباره رندر می‌شود؛
و اصلاحِ یک غلطِ تایپی یک رندر است نه یک تولیدِ دوباره. اگر متن داخلِ پیکسلِ مدل برود،
هر سه گران و شکننده می‌شوند و **هیچ‌کدام بعداً قابلِ جبران نیست**.

## دستورهای عملیاتی

```bash
# دیپلوی
# 🔴 `--exclude '.env'` اجباری است. `.env` روی سرور هست و در مخزن نیست؛
# بدونِ این استثنا، `--delete` رمزِ دیتابیس و FLOWSTUDIO_SECRET و رمزِ پنل
# را با هم پاک می‌کند و کانتینرِ بعدی با پیش‌فرض‌ها بالا می‌آید.
# همیشه اول dry-run؛ خروجیِ درست هیچ خطِ `deleting` ندارد.
cd ~/Projects/flowstudio
rsync -avz --dry-run --delete --exclude node_modules --exclude .next --exclude .git \
  --exclude '.env' --exclude '.DS_Store' --exclude 'docs/90-*' \
  ./ root@62.220.123.55:/opt/flowstudio/ | grep -i deleting
rsync -az --delete --exclude node_modules --exclude .next --exclude .git \
  --exclude '.env' --exclude '.DS_Store' --exclude 'docs/90-*' \
  ./ root@62.220.123.55:/opt/flowstudio/

# فقط api و web بازساخته شوند — بیلدِ کارگر کرومیوم دارد و ~۲۰ دقیقه است
ssh root@62.220.123.55 'cd /opt/flowstudio && docker compose -p flowstudio -f deploy/docker-compose.prod.yml up -d --build api web'

# 🔑 بعدِ هر تغییرِ رجیستری، سید باید بخورد وگرنه فیلدهای متنی روی سرور
```
