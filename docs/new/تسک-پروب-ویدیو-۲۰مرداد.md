# تسک: پروب ویدیو

> 📌 **این پوشه مبدا کار است.** سندهای قدیمی مرجع تاریخچه و معماری‌اند؛
> کار روزمره از این‌جا شروع می‌شود.

**پروژه:** فلواستودیو · **قلم ۹** · **اندازه:** ۲ روز
🔴 **بلوکه به کلید واقعی یک تجمیع‌کننده — کار لهراسبی**

## چرا این کار قبل از کد ویدیو می‌آید

⚠️ **تجمیع‌کننده مسئله ویدیو را حل نمی‌کند.** متن و تصویر فراخوان همگام سازگار با
OpenAI‌اند؛ ویدیو نیست. هر موتور یک API کار ناهمگام است (`submit → poll → fetch`) با
شکل متفاوت به‌ازای هر فروشنده. هیچ استانداردی ندارد.

⇒ روتر موجود برای ویدیو **قابل استفاده مجدد نیست**؛ آداپتر ناهمگام از صفر لازم است.

**پیش‌نیاز قطعی:** یک فراخوان دستی واقعی، تا شکل پاسخ معلوم شود. قبل از آن، نوشتن
کد ویدیو حدس زدن است.

## گام‌ها

۱. **لهراسبی:** کلید واقعی یک تجمیع‌کننده. در `/admin/models`: نام دلخواه، آدرس پایه
   سازگار با OpenAI، کلید واقعی. بعد یک مدل با نوع `TEXT` و تیک مصرف تجاری.
   بلافاصله بعدش `/studio` کار می‌کند.
۲. با همان کلید یک فراخوان دستی به مدل ویدیو بزن و **عین پاسخ** را در
   `evidence/` بنویس.
۳. از روی پاسخ واقعی، آداپتر ناهمگام را طراحی کن.
۴. تصمیم بگیر کدام مدل ویدیو در روز اول.

## تعریف تمام‌شدن

یک پاسخ واقعی از یک موتور ویدیو در `evidence/` نشسته و شکل API معلوم است.

## وقتی تمام شد

```bash
node ~/Projects/.localhub/control/mark.mjs flowstudio 9 done
```
