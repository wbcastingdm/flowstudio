## ۲) معماری در سه خط

```
کاربر → /studio → ایده
        ↓ (بدون کلید: برنامه‌ریز محلی · با کلید: مدل متنی)
      شات‌لیست کارگردانی‌شده
        ↓ دکمه «بساز» → JobGroup + PlanStep×۳ به ازای هر نما + Job
      صف (قفل دیتابیسی)
        ↓ کارگر برمی‌دارد
      زمینه HTML→PNG ← لایه شفاف متن HTML→PNG ← ffmpeg حرکت+overlay
        ↓ همه نماها تمام
```

**هر گام یک ردیف `Generation`** با نسخه دقیق موتور، زمان اجرا، هش پارامتر،
هش خروجی و ثانیه خروجی. یعنی معیار انتخاب مدل (CPAS) از امروز محاسبه‌پذیر است.

## ۳) کارهای مانده — به ترتیب ارزش

### ⭐ ۱. صدا: گام `tts` را واقعی کن

**چرا اول:** خروجی امروز بی‌صداست. ویدیوی بی‌صدا در ایران عملا منتشر نمی‌شود.
و صدا مسئله «مدت هر نما» را هم حل می‌کند: امروز مدت **حدس** است، با صدا از خود
گفتار درمی‌آید.

تاکسونومی آماده است (`STEP_TYPES` شامل `tts` و `stt` و `subtitle`)، ولی هیچ
اجراکننده‌ای ندارند. قرارداد از وبکستینگ خوانده شد و ساده است:

```
POST {baseUrl}/audio/speech          { model, input, voice }  → بایت صوتی
POST {baseUrl}/audio/transcriptions  multipart: file, model, language=fa → { text }
```

کارها:
- `apps/worker/src/steps/tts.ts` — متن نما → فایل صوتی، ذخیره با همان
  `store()`، ردیف `Generation` با `outputDurationSec` از `ffprobe`.
- در `render.service.ts` گام `tts` را **پیش از** `programmatic_motion` به
  زنجیره اضافه کن و `dependsOn` را ببند.
- در `chain.ts` مسیر `programmatic_motion` مدت نما را از صدا بگیرد، نه از
  `shot.durationSec`.
- در `packages/motion/src/presets.js` ورودی صوتی به `buildLayeredFfmpegArgs`
  اضافه شود (`-i audio` + `-map` + `-c:a aac -shortest`).

🔴 **این گام پولی است.** یعنی `STEP_COST_COINS.tts` باید عدد واقعی بگیرد و
آن‌وقت `budgetCap` صفرِ امروز جلویش را می‌گیرد با پیام D-006 — که **درست
است**، نه باگ. مالک باید عدد سقف را تعیین کند.

### ⭐ ۲. زیرنویس: گام `subtitle`

از خروجی `stt` روی فایل صوتیِ گام قبل، با زمان‌بندی. **فایل SRT بساز، نه
پیکسل** — سوزاندنش روی تصویر کار `programmatic_motion` است و از همان لایه
شفاف متن رد می‌شود (قاعده ۹: متن هرگز داخل پیکسل مدل نمی‌رود).

### ۳. زمینه از مدل تصویر، به‌جای گرادیان

معماری از همین حالا آماده است: کافی است در `render.service.ts` گام
`html2image`ِ لایه **زمینه** با `text2image` عوض شود. لایه متن دست نمی‌خورد،
مونتاژ دست نمی‌خورد، کارگر دست نمی‌خورد. **بلوکه به کلید واقعی.**

### ۴. اتصال فایل نهایی به انتشار — ✅ کد آماده، دیپلوی نشده

انجام شد و لوکال آزموده شد (۲۱ بند سبز، `evidence/sprint-publish-and-3moves.txt`):
`publish()` حالا `assetId` را قفل می‌کند، مسیر عمومی
`GET /api/public/works/:id/video` با پاسخ بازه‌ای فایل را می‌دهد، صفحه
`/w/[id]` پخش‌کننده دارد و پنل زنده دکمه «عمومی کن / برداشتن».

🔒 شرط انتشار **داخل خود کوئری** است ⇒ برداشتن بلافاصله فایل را می‌بندد.
🔑 پاسخ بازه‌ای اجباری بود: بدونش نوار زمان کار نمی‌کند و سافاری اصلا
   ویدیو را شروع نمی‌کند.

**همراهش: استودیو از شش حرکت به سه حرکت رسید.** چهار کارت شماره‌دار یک جعبه
و یک کشو شدند، فیلدهای متنی اجباری اختیاری شدند، و «ساخت شات‌لیست» با «بساز»
یکی شد — ولی **مشروط**: پنل اول `GET /render/estimate` می‌زند و فقط وقتی
برآورد دقیقا صفر است خودکار صف می‌کند. هر عدد بزرگ‌تر ⇒ «تأیید و بساز — N
سکه». گاردریل ۵ نشکست.

⚠️ برای این کار `STEP_COST_COINS` از کارگر به `@flowstudio/ledger` رفت و
تعریف زنجیره در `render.service.ts` به `chainFor()` استخراج شد — یک منبع
برای صف‌کردن و برآورد.

### ۵. قلم ۹ — پروب ویدیو

🔴 همچنان بلوکه به کلید واقعی. سند `تسک-پروب-ویدیو-۲۰مرداد.md` دست‌نخورده
معتبر است: تجمیع‌کننده مسئله ویدیو را حل نمی‌کند، هر موتور ویدیو API ناهمگام
خودش را دارد، و بدون یک پاسخ واقعی نوشتن آداپتر حدس زدن است.

### ۶. بستن در باز ورود — قلم ۲۱

پیش از اولین ریال واقعی. امروز هر کسی با هر شماره و رمز `123456` وارد می‌شود
و صفحه ورود خودش رمز را نشان می‌دهد.

## ۴) 🔴 تله‌هایی که در این سشن خوردیم

هیچ‌کدام از روی کد پیدا نمی‌شوند:

۱. **ایمیج API بسته مشترک را نمی‌ساخت.** `WalletService` از
   `@flowstudio/ledger` تایپ می‌خواند ولی Dockerfile هرگز `tsc` آن را نمی‌زد.
   روی مک کار می‌کرد چون از قبل ساخته بود ⇒ **فقط داخل داکر دیده می‌شد**.
   حالا دو خط لازم است و هر دو در `apps/api/Dockerfile` هستند:
   `npm run build --workspace=@flowstudio/ledger` و `COPY … /packages`.
   دومی حتی در بیلد خطا نمی‌داد و موقع اجرا کرش می‌کرد — symlink ورک‌اسپیس به
   پوشه‌ای اشاره می‌کند که در ایمیج نیست. **هر بسته مشترک تازه‌ای هم همین دو
   خط را می‌خواهد.**

۲. **درگاه نمونه با کلید الکی `/studio` را می‌شکند.** روتر متن هر مدل
   ثبت‌شده‌ای را کاندیدا می‌گیرد؛ چند ردیف نمایشی یعنی برنامه‌ریز محلی کنار
   می‌رود و هر کاربر ۵۰۳ می‌گیرد. برای همین کاتالوگ در جدول جدا
   (`GatewayPreset`) نشست و فقط فرم را پر می‌کند.

۳. **`Shot.order` در هر سکانس از یک شروع می‌شود** ⇒ روی تصویر دو بار «نمای ۱»
   نوشته می‌شد. جای درست `globalPosition()` در `chain.ts` است. همین تله در
   پنل زنده هم بود و با اندیس آرایه حل شد.

۴. **فونت باید data-URI باشد.** کروم بدون سر با `file://` گاهی فونت را رها
   می‌کند و بی‌صدا به فونت سیستم می‌افتد؛ روی آلپاین فارسی جعبه‌جعبه می‌شود و
   خروجی ffmpeg سبز می‌ماند.

۵. **`--headless=new` اجباری است** برای PNG شفاف. در حالت قدیمی پرچم
   `--default-background-color=00000000` نادیده گرفته می‌شود و لایه متن با
   زمینه سفید بیرون می‌آید — یعنی یک مستطیل سفید تمام‌قد روی ویدیو.

۶. **مهاجرت پیش از `up`، با ایمیج تازه.** اگر اول کانتینر بالا بیاید، API چند
   ثانیه روی ستون‌هایی کوئری می‌زند که هنوز نیستند:
   ```bash
   docker run --rm --network flowstudio_default -e DATABASE_URL=… \
     flowstudio-api npx prisma db push --schema=prisma/schema.prisma --skip-generate
   ```

۷. ⚠️ **بیلد ایمیج کارگر را روی مک نزن.** کرومیوم و ۲۰۱ بسته وابسته، دیسک را
   پر کرد و کل پوسته از کار افتاد. روی سرور بزن (~۲۰ دقیقه، بعدش کش می‌شود).

۸. **رقم لاتین وسط متن فارسی** — هم روی تصویر هم در رابط. مبدل در سه جا هست:
   `html.ts`، `local-planner.ts`، و هر صفحه وب یک `toFa` دارد.

## ۵) نقشه کد تازه

```
packages/ledger/          دفتر سکه، بدون فریم‌ورک. API و کارگر یک پیاده‌سازی
apps/worker/
  src/main.ts             حلقه، برداشتن کار، بازگرداندن یخ‌زده، خاموشی نرم
  src/chain.ts            زنجیره یک نما + ردیف تولید + دارایی نما
  src/finalize.ts         مونتاژ و بستن گروه (قفل مسابقه با updateMany)
  src/render/html.ts      دو لایه: زمینه بی‌متن، متن شفاف. فونت data-URI
  src/render/chromium.ts  HTML → PNG
  src/render/ffmpeg.ts    پل به packages/motion (ESM از CJS)
apps/api/src/modules/render/   برنامه‌ریز: پاکت + پلان + صف + وضعیت زنده
apps/api/src/modules/projects/local-planner.ts   شات‌لیست بدون مدل
apps/api/prisma/seed-gateways.ts                 کاتالوگ ۷ درگاه نمونه
apps/web/app/render-panel.tsx  پنل زنده، مشترک بین استودیو و کتابخانه
```

```bash
DATABASE_URL="postgresql://flowstudio:flowstudio_dev_password@localhost:5432/flowstudio?schema=public" \
STORAGE_DIR=~/Projects/flowstudio/.storage node apps/worker/dist/main.js
```
