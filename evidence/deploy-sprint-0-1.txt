════════════════════════════════════════
۰) وضعیتِ DNSِ دامنهٔ مستقل — بلوکر
════════════════════════════════════════
$ dig +short flowstudio.ir A
(خالی)
$ dig flowstudio.ir NS +noall +authority @8.8.8.8
ir.  900  IN  SOA  a.nic.ir. info.nic.ir. ...

⇒ دامنه ثبت شده ولی **هیچ نیم‌سروری ندارد** (NS تفویض نشده). تا وقتی مالک
در پنلِ ثبت‌کننده نیم‌سرورها را به Cloudflare ندهد و رکوردِ A بسازد، هیچ‌چیز
روی flowstudio.ir بالا نمی‌آید. کانفیگش آماده است:
deploy/nginx/flowstudio.ir.conf

پس فعلاً همه‌چیز روی زیردامنهٔ کارکننده دیپلوی شد تا قابلِ دیدن باشد.

۱) کانتینرها روی سرور
════════════════════════════════════════
$ docker ps | grep flowstudio
flowstudio_api        Up (healthy)
flowstudio_web        Up (healthy)
flowstudio_postgres   Up (healthy)
flowstudio_redis      Up (healthy)

⚠️ باگِ واقعی که در دیپلوی پیدا و رفع شد:
کانتینرِ API در دورِ اول کرش‌لوپ می‌زد:
  "PrismaClientInitializationError: Unable to require libquery_engine-linux-musl.so.node
   Details: Error loading shared library libssl.so.1.1: No such file or directory"
علت: ایمیجِ alpine با OpenSSL 3 است ولی Prisma پیش‌فرض engineِ openssl-1.1 را
می‌سازد. رفع: binaryTargets = ["native","linux-musl-openssl-3.0.x"] در
schema.prisma + apk add openssl در Dockerfile.
🔴 این خطا **فقط داخلِ داکر** دیده می‌شود — روی مک هرگز.
