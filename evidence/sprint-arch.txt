۳) آزمون یکپارچه — apps/api/test/registry.check.ts

■ ۱) نوع تولید و زیرشاخه‌های وابسته به آن
✅ نوع‌های فعال  →  ["ad","short_film","documentary"]
✅ کل نوع‌ها شش تاست  →  6
✅ تبلیغ لحن می‌پرسد  →  true
✅ تبلیغ ژانر نمی‌پرسد  →  false
✅ فیلم کوتاه ژانر می‌پرسد  →  true
✅ فیلم کوتاه لحن نمی‌پرسد  →  false

■ ۲) اعتبارسنجی زیرشاخه در برابر شمای همان نوع
✅ ورودی درست تبلیغ  →  {"tone":"warm","brand":"نان سنگک"}
✅ فیلد اجباری غایب  →  «نام برند یا محصول» لازم است
✅ مقدار خارج از فهرست  →  «لحن» باید یکی از warm، professional، energetic باشد
✅ ژانر روی تبلیغ پذیرفته نمی‌شود چون اجباری‌اش غایب است  →  «لحن» لازم است · «نام برند یا محصول» لازم است
✅ فیلد ناشناخته دور ریخته می‌شود، نه ذخیره  →  {"tone":"warm","brand":"x"}

■ ۳) سطح خدمت با سیاست، نه با فهرست شناسه مدل
✅ برنزی سقف هزینه دارد  →  5
✅ طلایی بی‌سقف است  →  null
✅ طلایی همه گام‌ها را می‌دهد  →  0
✅ قیمت هیچ سطحی اختراع نشده  →  [null,null]
✅ مدت مجاز در برنزی رد نمی‌شود
✅ مدت ۶۰۰ ثانیه در برنزی  →  سطح برنزی تا 30 ثانیه است و درخواست 600 ثانیه بود.
✅ لیپ سینک در برنزی  →  این گام‌ها در سطح برنزی در دسترس نیستند: lipsync
✅ لیپ سینک و مدت یک ساعته در طلایی مجاز است

■ ۴) قوانین رایگان — مجوز مقصد انتشار را فیلتر می‌کند
✅ غیرتجاری فقط دانلود  →  ["DOWNLOAD"]
✅ بدون قید یعنی همه مقصدها  →  []
✅ غیرتجاری برای دانلود مجاز  →  true
✅ غیرتجاری برای فلک ممنوع  →  false
✅ بدون قید برای فلک مجاز  →  true
✅ برای دانلود هر دو ترک دیده می‌شوند  →  2
✅ برای فلک فقط ترک بدون قید دیده می‌شود  →  ["ترک آزمون بدون قید"]
✅ متن شرط برای نمایش به کاربر آماده است  →  true

■ ۵) افزودن نوع تولید تازه بدون مهاجرت
✅ یک ردیف اضافه شد، بدون هیچ تغییر شما  →  1
✅ شمای فرمش بلافاصله کار می‌کند  →  {"host":"رضا"}
✅ غیرفعال است پس در فهرست کاربر نمی‌آید  →  false

■ ۶) کدهای دلیل — یک تاکسونومی، یک قرارداد نام‌گذاری
✅ شش دسته دلیل  →  ["compliance","legal","other","quality","rule_exception","technical"]
✅ هیچ کد یا دسته‌ای با قرارداد قدیمی نمانده  →  []

✅ همه بندها گذشت


۴) رفتار واقعی از راه HTTP — گاردها پیش از هر خرج عمل می‌کنند

  ▸ نوع ناشناخته
     نوع تولید «jazz_hands» تعریف نشده.
  ▸ نوع غیرفعال
     نوع «انیمیشن و انیمه» فعلا در دسترس نیست.
  ▸ تبلیغ بدون فیلد اجباری
     «لحن» لازم است · «نام برند یا محصول» لازم است
  ▸ تبلیغ با ژانر به جای لحن — زیرشاخه نوع دیگر پذیرفته نمی‌شود
     «لحن» لازم است · «نام برند یا محصول» لازم است
  ▸ مدت خارج از بازه نوع (تبلیغ ۱۰ دقیقه‌ای)
     مدت «تبلیغی» باید بین 6 تا 60 ثانیه باشد.
  ▸ فیلم ۱۰ دقیقه‌ای در سطح برنزی — گارد سطح خدمت
     سطح برنزی تا 30 ثانیه است و درخواست 600 ثانیه بود.
  ▸ همان درخواست در سطح طلایی — تا فراخوان مدل واقعی پیش می‌رود
     هیچ مدلِ TEXTی با commercialUse=true ثبت نشده  ← ۵۰۳ صادقانه، نه خطای ساختگی

۵) آنچه این فاز اثبات می‌کند
  - زیرشاخه‌ها واقعا به نوع تولید وابسته‌اند: تبلیغ لحن می‌پرسد، فیلم ژانر.
  - افزودن نوع تولید تازه یک ردیف است، نه یک مهاجرت.
  - سطح خدمت با سیاست کار می‌کند نه با فهرست شناسه مدل، پس افزودن مدل
    تازه به رجیستری هیچ سطحی را نمی‌شکند.
  - مجوز رسانه مقصد انتشار را فیلتر می‌کند: ترک غیرتجاری برای دانلود
    دیده می‌شود ولی برای فلک اصلا در فهرست نمی‌آید.
  - قیمت هیچ سطحی اختراع نشده (null است) — D-204 دست‌نخورده مانده.
